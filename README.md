# Gestor de Almacenes La Taberna Lions Gold

> **Sistema integral de control de almacén, punto de venta multidivisa (Bs/USD), libreta de fiados con WhatsApp y cuadre de caja.**  
> Diseñado y desarrollado con excelencia por **Smith Bussines Solutions 2026** para el comercio en Venezuela.

---

## 🌟 Características Principales

- **Control de Inventario y Almacén en Tiempo Real**:
  - Seguimiento de existencias de licores finos, cajas de cerveza, vinos y víveres.
  - Alertas automáticas de stock mínimo para reposición oportuna.
  - Ajustes rápidos de entrada (+), salida (-) y mermas.
  - Valoración total del almacén calculada en USD y Bolívares.

- **Punto de Venta Rápido (POS) Multidivisa**:
  - Facturación ágil para mostrador y barra.
  - Tasa de cambio oficial/paralela (BCV) en tiempo real con conversor instantáneo.
  - Métodos de pago venezolanos: **Pago Móvil**, **Efectivo USD** (con cálculo de vuelto), **Efectivo Bs**, **Punto de Venta (Tarjeta)** y **Zelle**.
  - Emisión de comprobantes digitales enviables en 1 clic a WhatsApp.

- **Libreta Digital de Fiados & Deudas**:
  - Control de cuentas por cobrar para clientes de confianza.
  - Recordatorios de cobro automáticos con mensaje preformateado para WhatsApp con el monto en $ y Bs al cambio del día.
  - Registro de abonos parciales e historial detallado de transacciones.

- **Control de Caja Chica & Gastos Operativos**:
  - Libro de ingresos y egresos diarios (compras de hielo, fletes, bolsas, suministros, nómina).
  - Balance neto y cuadre de caja en tiempo real.

## 🚀 Instalación y Ejecución Local

1. Clonar el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/gestor-almacenes-la-taberna-lions-gold.git
   cd gestor-almacenes-la-taberna-lions-gold
   ```

2. Instalar dependencias:
   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Construir para producción:
   ```bash
   npm run build
   ```
